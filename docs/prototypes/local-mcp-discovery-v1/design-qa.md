# 本机 MCP 发现原型检查记录

范围：独立静态原型与需求技术简稿。正式 apps/web、服务端 RPC 和真实用户配置均未触碰。

## 交互检查点

- 点击“从本机发现”即扫描 Codex 与 CCSwitch 示例来源，流程显示三步：发现结果、确认摘要、导入结果。
- “修改来源”展开 Codex / CCSwitch 选择、可选指定文件格式与服务端绝对路径；重扫后回到结果。标准 MCP JSON 的缺配置与不支持状态只用于两条虚构条目。
- 页面唯一的全局提示声明示例数据；结果行显示名称、来源名、协议、来源状态和导入状态，不重复标注示例或配置解析过程。
- Codex 与 CCSwitch 常见来源条目状态仅为可导入、已存在、配置冲突；来源停用标记不阻止选择，也不改变 Synara 或其他应用开关。
- 首次进入时所有行均未选中。已存在默认跳过且不可选；冲突项显式选跳过、另建唯一 ID 或更新现有连接；JSON 示例中的缺配置和不支持条目不可选。
- 展开冲突时并排显示“Synara 当前”与“发现配置”的安全摘要示例；stdio 只示范命令 basename，不展示完整路径、raw args 或任何值。启动参数或环境来源等其他配置不同，值不在预览中显示。
- 搜索、来源筛选、冲突展开、返回确认摘要时保留已做选择；更新展示新版本和任务原绑定保留。
- 演示状态可覆盖扫描失败、无结果和确认前来源变化。变化场景按条目显示失败，重试先经过“重新扫描并重试”操作。
- 成功入口“查看连接”只显示连接配置摘要；“检查连接与配置授权”只展示后续步骤说明，不运行检查、不读取工具，也不显示健康或授权结果。
- 主题与字号控件可在原型内调节；480px 规则将结果表格折叠为字段卡片。
