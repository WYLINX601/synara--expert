# Hub V0.5：协作过程评审稿

2026-10-22，用户选择「先优化协作过程」。本稿是独立 HTML 的产品讨论原型，不是正式产品实现，也不构成开发、发布或真实任务执行授权。

[打开 V0.5](Hub_交互原型_V0.5.html) · [对照 V0.4](sources/Hub_交互原型_V0.4.html) · [现有能力差异](README.md)

## 这次的设计选择

1. **Hub 仍是对协调员说话的地方。** 等待产品经理回答时，不自动改变输入框收件人。用户可以进入专业线程，也可以点击「在此回复」；后者明确标记对象与工作，并允许取消定向。Hub、线程与定向回复分别保留草稿，避免未发送内容串到另一个对象。
2. **工作卡先说现在要做什么，再展开过程。** 等待用户时直接显示问题或待确认成果、对应版本和下一步；操作区放在阶段细节之前。专业审核通过而用户未放行时，不把整个阶段画成已完成。
3. **退回修改后由专家继续修订。** 有完整修改意见时进入「正在修订」，不重新要求回答旧问题；只有确实缺少必要输入时才出现等待用户。原作者线程保留修改要求。
4. **暂停保留进度。** 整体显示已暂停，各阶段、已有线程、成果与版本继续可见；恢复回到原阶段。暂停期间普通讨论可以继续，不代表放行任务。
5. **批准对象和范围直接可见。** 需求方案 vN 与审核对象对应；只授权方案阶段时，操作是「确认并完成」，不出现已获授权的开发步骤。

这些是供用户体验的新稿选择，尚未成为正式产品最终规范。

## 保持的边界

- 继续使用主对话、工作卡、专业线程和一个成果检查面板。
- 创建入口、专家团列表与配置沿用 V0.4，本轮没有重新设计。
- 不引入常驻 Graph 编辑器，不新增并行的业务状态源。
- 原型只有一份模拟计划；多计划选择、回复归属与待处理汇总留待下一轮设计。
- 底部场景切换器仅用于模拟，不能证明真实模型、审批身份、版本锁定、取消或恢复有效。
- 未解决原 V0.4 创建设置中的来源项目可改设计与现有服务契约的冲突；该问题已记录在差异评审中，正式开发前必须收口。

## 建议体验路径

确认计划 → 在 Hub 问协调员一个问题（应保持等待补充）→ 在此回复产品经理 → 取消定向并检查草稿 → 重新定向回复 → 模拟审核完成 → 退回修改 → 查看原线程修改要求 → 模拟重新审核 → 确认成果 → 暂停／恢复 → 查看成果。

另检查「调整计划 → 只完成方案阶段」后再确认与放行，确保不会进入开发。

## 验证记录

只验证 HTML 演示，不沿用 V0.4 外部测试数量或正式应用测试结论。

| 检查               | 本轮结果                                                                 |
| ------------------ | ------------------------------------------------------------------------ |
| 计划确认           | 确认后留在 Hub，等待必要输入；输入默认仍发给 Hub                         |
| 普通讨论／显式回复 | 普通讨论保持原阶段；选择「在此回复」后发给产品经理，随后模拟进入审核     |
| 草稿               | Hub 草稿与定向草稿切换后各自恢复；线程草稿单独保存                       |
| 退回与版本         | v2 退回后进入修订，原产品经理线程显示修改意见；重新模拟审核时明确审核 v3 |
| 成果历史           | 成果列表保留 v2 已退回、v3 已确认及各自的审核对象                        |
| 暂停与恢复         | 开发线程、已确认方案和历史仍可见；暂停消息仅记录；恢复回到开发阶段       |
| 范围               | 只完成方案阶段时显示「确认并完成」，完成后不进入开发                     |
| 布局               | 1280×720 放行主操作在首屏可见；600×800 页面及主要内容无横向溢出          |
| 语法               | 独立脚本语法检查通过                                                     |

浏览器发现的暂停文案歧义及新版计划补充要求不可见问题已在本稿修复并复核。多计划、真实审批身份与版本锁定、真实取消恢复、模型执行、移动端完整操作与辅助技术仍未验证。

原型底部「模拟事件」可以跳转演示阶段，会保留部分演示历史；顺序体验可刷新页面从计划草案开始。草稿仅在当前页面运行期间保留，刷新不保证恢复。
