# 本机 MCP 发现与导入：需求与技术简稿

状态：交互原型阶段。下列内容是目标约束，不表示候选 RPC、权限校验或导入能力已通过最终验收。

## 用户流程

1. 在 MCP 连接列表选择“从本机发现”，立即扫描 Codex 与 CCSwitch 常见来源并进入结果列表；发现视图可返回 MCP 列表。
2. 需要更改来源时打开“修改来源”，选择 Codex、CCSwitch，或启用指定文件并选择 Codex TOML、标准 MCP JSON、CCSwitch DB 和 Synara 服务端绝对路径。重新扫描后返回结果列表。
3. 扫描只读返回元数据与安全摘要。用户逐项查看来源、协议、来源状态和导入状态。
4. 可导入条目默认不勾选；已存在默认跳过。配置冲突必须显式选跳过、另建唯一 ID 或更新现有连接。缺配置和不支持的条目不能选入导入。
5. 三步流程为发现结果、确认摘要、导入结果。确认摘要逐项列出新增、更新、跳过和不可导入数。更新生成新版本，已有任务保留原绑定版本。
6. 导入按条目返回成功或失败；来源摘要变化时拒绝该条写入，允许重新扫描后重试。

来源状态只描述来源配置。CCSwitch 的 enabled_codex 按“Codex 中启用 / 停用 / 未标注”呈现；它不代表 Synara 连接开关、其他应用开关或 Expert 授权。来源启用标记属于扫描预览快照；若扫描后该标记变化，需要重新扫描，但它不会写成 Synara 或其他应用的开关状态。标准 MCP JSON 显示源配置状态，不伪造应用开关字段。导入不连接服务，不授予 Expert 权限。

## 目标服务端边界

- 目标提供仅由连接所有者调用的 discover/import RPC；当前服务端实现位于候选工作树，权限边界与服务端行为仍待验证。配置解析在 Synara 服务所在电脑执行，支持 Codex 用户配置、CCSwitch 只读数据库和显式文件。
- parser 可读取源配置以解析服务定义；扫描响应只返回连接元数据和安全摘要，不返回或持久化原始密钥值、header 值或认证 payload。扫描候选以短期 scanId 缓存在服务端。
- 当前候选 RPC 的 candidate `summary` 是单一安全字符串：stdio 显示命令 basename，HTTP 显示 origin。冲突对比可从 Synara 当前连接计算同类摘要；其它启动参数或环境来源等差异只用概括提示，不在预览中显示值、raw args、完整路径或未由 RPC 提供的 env/header 名称与 cwd 差异。
- 导入时逐条重读来源条目并与扫描 fingerprint 比较；若本次读取时已变化，该条失败且不写入。通过比较后，以该次读取的 command、args、cwd、URL 等连接配置快照生成 Synara 版本，逐条返回结果并允许部分成功。
- 来源应用与 Synara 不共享事务或文件锁：此流程不保证来源在检查与 Synara 写入之间始终不变，不承诺跨应用原子提交，也不做多轮来源复查。
- 导入只写 Synara 连接配置。它不回写 Codex、CCSwitch 或任意其他应用，不替用户连接服务，也不授予 Expert 授权。
- 字面量环境变量和 headers 以来源引用保存，形状为 {kind, path, entryId, names}；每次建连时按引用读取来源当前值，不在扫描或导入时冻结或复制密钥值。来源值后续变化会影响之后的连接读取；值缺失或格式不合规时连接无法解析这些引用。
- command、args、URL 固定在被导入的连接版本内。更新应创建新版本；任务继续使用其原有绑定版本。
- 不覆盖 OAuth 登录继承，也不支持任意 CLI 配置格式。

docs/prototypes/local-mcp-discovery-v1/index.html 使用硬编码示例数据，只演示列表、扫描状态、条目选择、冲突处理、确认摘要和逐条导入结果。页面不访问文件系统、数据库或网络，不调用 MCP、连接检查、工具读取或授权 API；成功入口只展示连接配置摘要或下一步说明。缺配置与不支持只在指定标准 JSON 的虚构条目上显示，不代表真实来源能力结论。
