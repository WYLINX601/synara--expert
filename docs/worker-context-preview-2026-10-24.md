## 后续排查与修复

已确认测试模拟服务存在两个问题：未检查路径／方法就把每个 HTTP 请求体当作 JSON 解析；`createServer` 的异步处理错误没有交回所属测试。旧版取消用例连续／并发共 390 次未复现历史错误；仅增加诊断的完整回归也为 18,038 通过、40 跳过、0 未处理错误，因此原始运行的具体请求来源仍未取证。

独立实验调用现有 `buildLocalServerProcesses` 和默认 `enrichLocalServerProcessesWithPageTitles`，将监听器放在 `turbo run test` 的进程祖先条件下。实际本地服务监测会向模拟服务发送无正文的 `GET /`，User-Agent 为 `SynaraLocalServerMonitor/1.0`，完整请求体长度为 0；旧夹具随即产生相同的 `Unexpected end of JSON input`。这证明可复现的触发机制，不等于追溯确认历史请求的发送者。另行对照中，单纯 TCP 连通不会进入 HTTP 处理器，截断的非空 POST 则先在请求体读取时产生 `ECONNRESET`。

修复仅涉及 `stdioProxyScript.test.ts`：三种场景共用测试服务器，在解析前对不支持的路径返回 404、对非 POST 方法返回 405；异步处理错误由等待和清理流程重新抛出。原有取消、重复 ID 隔离、后续 ping、启动及 EOF 断言保留；新增探测请求及两项空／残缺 JSON POST 回归，坏 RPC 仍返回 500 并使等待与清理失败。独立只读审查无新增发现。未改变生产监测器、代理、UI、超时或 skip。
