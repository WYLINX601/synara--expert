# 生产界面驱动的高保真交互原型

## 目标与边界

高保真是**最终前端实现、真实界面组成、完整行为和状态连续性**，不是相似配色或可点击的静态稿。交互原型用于在整体能力完成前审核前端，尽早发现并修正问题，避免开发完成后返工。已有产品默认采用“先原貌复原，用户确认，再增量优化”。

本 Skill 是方法，不授予工具、文件、网络、生产数据、发布或安装权限。遵守当前宿主、仓库和用户授权；没有可用工具时报告准确限制，不绕过宿主。不要修改固定 Skill 快照或声称此文件已自动安装到专家。

适用于已有产品的交互原型；纯概念探索可以另用低保真方法，但必须先标明它不是当前产品的高保真复原。可与 BMad UX 并用，不替代官方 DESIGN / EXPERIENCE 契约、需求路由或用户验收。

## HF-00 原型即成品：提前评审，不另做演示实现

- 原型是最终成品前端的可运行评审版本；评审通过后的交互代码应直接保留并进入产品，而不是由开发者照着原型重新实现。未验收不等于可发布，“原型即成品”也不代表后端或原生能力已经完成。
- 在获授权范围内尽可能完整实现前端能力：实际控件、状态转换、数据保持、校验、加载、空态、失败恢复、取消、键盘与无障碍、响应式布局。不要只实现顺利路径，也不要用可点击占位控件代替承诺的功能。
- 前端状态和行为由最终业务组件及其状态所有者负责。评审工具只负责注入边界输入、选择 fixture 和观察结果，不另建一套产品状态机、计时器或点击脚本来表演结果。
- 数据或宿主暂不可用时，仅在明确的契约边界使用隔离适配器；沿用真实请求、事件、错误和取消语义。接入真实服务时应替换边界适配器，而非重写界面及交互逻辑。模拟证明前端处理能力，不证明外部执行成功。
- 开始前列出获授权能力及验收矩阵：每项对应入口、完整路径、异常/恢复、状态所有者、真实实现位置、依赖边界与验收证据。缺少接口信息先查现有契约；仍不可得时明确阻塞，不编造协议或悄悄缩减范围。
- 单独预览只是运行环境隔离，不是复制第二套前端的理由。默认让预览与产品消费同一实现；受现有授权限制不能修改产品代码时，明确交付尚未达到可直接集成标准，取得扩展授权后再迁入共享实现，不把预览专用补丁称为最终实现。
- 窗口边缘操作也是产品能力：收起、恢复、返回主窗口、状态提示必须在最终产品表面实现并参与评审，不能放在评审工具条中，再解释为“以后由原生标题栏补上”。可以模拟窗口管理接口，但入口、可达性、布局和状态保持必须复用最终前端代码；抽屉折叠后仍须有退出和恢复路径。
- 按三层分别报告：前端能力已实现/已验证、外部依赖已接通/仍模拟、用户已认可/尚待评审。尽可能完整不是无限扩展范围，也不授予生产接入、安装或发布权限。

## HF-01 锁定意图，不把场景缩成产品

- 区分产品范围、代表性场景、当前任务。一个写作示例不能推导出“只服务写作”。
- 收集用户明确认可的截图、交互、痛点、不得改变的元素及本轮改动范围；不要重复询问已有答案。
- 为需求、状态、流程保留稳定编号。注明哪些已认可、哪些是待评审设计选择。
- 将“基线对齐”“原型优化认可”“产品实现验收”分开记录。

## HF-02 建立可追溯基线

查明当前工作区、源码版本、实际应用版本和本轮未提交改动；无法核实安装版与源码的映射，就写“映射未验证”，不冒称完全一致。

定位真实路由和父布局，记录其 Provider、状态所有者、主题、字体、翻译、订阅、快捷键、portal 与宿主接口。优先读现有浏览器 fixture / harness，而非先造演示壳。按仓库规则使用代码索引和语言服务定位组件与调用方。

交付目录沿用已有任务预览目录，不为每轮复制全仓库、node_modules 或安装包。新端口、数据 home、进程与保留原因按项目环境规范登记。

## HF-03 选择最高层级的真实复用

按以下顺序选择：

1. **同一真实应用入口 / 路由树 + 必要依赖注入**：适合聊天、任务、窗口切换等强状态页面。
2. **真实业务组件 + 完整 Provider / 状态上下文**：只有父布局不属于要验证的行为时才选，说明省略内容。
3. **已有基础组件组成新增区域**：仅用于获授权的新交互，不用它替代已有业务组件。

不要把导入几个 Button、Textarea、图标称为“复用了现有交互”。不要重写一套 composer、transcript、审批行或菜单来凑截图。不要以复制整个业务组件作为默认方案；会形成两个实现。确需复制时先说明直接挂载的具体障碍、复制范围、同步与退出方式，并取得对应授权。

完整继承原生产 stylesheet、utility 扫描范围、字体、主题序列化、字号、语言、motion 和 portal 容器。独立构建根常常漏扫生产类名；先检查 CSS 构建，不能给原组件额外涂样式掩盖。

## HF-04 只替换数据和宿主边界

- 原组件、handler、状态机与消息路径使用最终实现；仅边界数据、执行结果、窗口尺寸等允许模拟并明确标示。不能以“只是原型”为由绕过真实前端校验、授权选择、状态处理或错误恢复。
- 尽可能复用项目已有测试传输与契约解码。拦截必须早于可能创建连接的模块导入；未支持请求明确失败，不返回万能成功对象。
- 防止真实后端、Provider、文件写入、摄像头、麦克风、剪贴板或外部网络被意外调用。只清理专用预览 origin / home，绝不重置日用数据。
- iframe 的 scripts、same-origin、forms、焦点与权限策略分别验证。允许同源脚本不等于安全沙箱；不要装载不可信代码。
- 原生窗口、置顶、跨应用焦点、系统托盘、快捷键、鼠标穿透、跨屏等，在网页中只能演示意图。除非真实宿主跑通，不声明已实现。
- 模拟模型名称仅为 fixture，不擅自改变真实 Provider 或用户模型偏好。

## HF-05 原貌复原门禁

优化之前，运行真实挂载并与用户参考比较：组成层级、尺寸与边缘、圆角、间距、字体、按钮位置、空态、有内容态、展开态、菜单和错误态。

先修复缺失主题、Provider、CSS、数据结构、权限或宿主接缝。不要用“大面板 / 新标题栏 / 新聊天框”绕过困难。记录视觉差异来源；内容、背景、模型等合成数据差异与界面差异分开。

基线未经确认时提供复原证据，请用户比对；已明确确认则不要再次要求同一确认。只有基线被认可后，才进入已授权优化。

## HF-06 增量优化，保持连续性

只改授权的交互增量。新增入口、面板边缘控件优先复用已有 Button、Menu、Tooltip、品牌组件与主题 token；没有可复用项时说明新建原因。

- 每条流程写明起点、触发动作、可见结果、返回方式和数据保持规则。
- 显示状态和任务状态分开：收起、隐藏、离开窗口不等于停止任务。
- 同一会话往返不重建组件树、不重载 iframe、不清草稿、不复制第二份会话状态。
- 提示来自实际读模型/模拟传输状态，不能由评审下拉框或固定延时伪造成功。
- 失焦、后台完成、待审批不擅自抢焦点或强制展开。输入法、菜单、Esc 行为遵循原有语义。
- 关闭可见层要处理键盘焦点和隐藏层的可聚焦性；保留任务执行。
- 需要动画时复用现有 motion，覆盖减少动态效果；不要另定一套时间常数。

## HF-07 验证流程，不只截图

运行实际原型，用宿主规定的浏览器/设备工具操作用户会使用的控件。遇到人工接管立即停手，等待交回。失败调用先检查已完成动作，再决定下一步。

覆盖本轮受影响路径：

- 唤起 → 输入 → 实际点击发送 → 进行中 → 完成；键盘提交不能替代按钮提交验证。
- 执行中收起 / 恢复、停止后的内容保留、后台完成是否保持低打扰。
- 待回答 / 待审批的确认、拒绝或取消；错误后的恢复。
- 模式/窗口往返时，同一线程、草稿、选择和滚动意图是否连续。
- 菜单与 portal 不被裁剪；小尺寸/低高度不遮住关键操作；键盘焦点不会进入隐藏层。

区分评审“注入某状态”和真实“操作后转换到该状态”。保留各自证据，不用前者冒充后者。至少运行一条包含多次往返的连续用户流程。

逐项核对 HF-00 的能力矩阵：每个获授权入口均能完成对应任务或呈现准确的外部依赖阻塞；不存在假成功、无效按钮或评审后仍需重写的前端路径。依赖模拟时验证真实前端对成功、失败和取消事件的处理，另外列出必须在真实服务/宿主中补做的检查。

截图用在需要像素证明的关键完成状态；生成后实际查看。测量重要的宽度/底边/焦点或 DOM 连续性，但不做仅检查源码存在的伪测试。按仓库要求跑格式、lint、类型及受影响测试；这些不能代替运行证据。

## HF-08 交付与方法复用

结论先行，包含：

1. 预览地址与产物路径；输入版本和本轮获授权的改变。
2. 最终前端实现位置、真实复用清单、模拟边界、新增组件及原因；说明预览与产品是否消费同一实现，以及接入剩余依赖是否需要改写前端。
3. 能力矩阵的逐项结果、已实际操作的状态转换与证据；未完成能力、失败、限制、未验证事项及其阻塞条件，不以“演示完成”替代交付。
4. 查看过的关键截图；用户下一步具体评审点。
5. 环境保留/停止方式、临时资源清理情况；不把生成文件或检查通过当作用户验收。

保持一份当前原型及权威交接记录，删除自己已被替代的演示组件；用户或其他任务的文件未经授权不删除。不要自动提交、推送、安装、发布或替换 Skill 库。

若用户要求长期使用此方法：交付独立 Skill 文件包；只有通过宿主授权的技能管理流程导入、绑定，并在新 Run 的目录中核实后，才声称已对未来会话生效。固定快照和禁用自学习的运行不允许原地篡改；不要承诺“我永远记住了”。
