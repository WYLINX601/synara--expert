## 运行与资源边界

复用唯一交付根；新增验证使用独立 home、凭据副本、端口与合成数据库。日用数据库、应用和原线程不改变。当前主机缺少 Xcode `actool`，若使用已安装 catalog 输入生成诊断包，必须在清单记录外部输入 hash，不称为可复现发行构建。Windows 原生运行、签名、安装、远端 CI 与发布分别需要实际结果及相应授权。

候选保留真实 Git 历史；已有其他工作树和恢复集不删除。验证凭据副本在实例关闭后清理，源码与脱敏证据留存。临时产物轮换遵循恢复验证和单一交付根政策。
