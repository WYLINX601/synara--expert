## 当前实施：流程导航与异常入口

按用户最新授权，将样式审阅版接入正式 `GraphBoard`，不再依赖 `hubGraphPreview` 参数。默认复用原生 `ComposerCapsulePopover` 收起，仅展示图标、协作流程、真实全局状态与展开箭头；移除计数和演示操作。展开后全局状态让位于横向节点，角色、短任务和状态各展示一次。同层依赖并排，窄窗口在图内横向滚动，任务名称省略并保留完整提示。

点击节点后才使用已有 `StageInspector` 展示详情。实际线程报告与服务端阶段检查分别标明来源；已知系统原因本地化，其他真实信息原样保留，不用示例填充。成果继续复用固定版本查看组件；线程、计划确认、暂停、恢复、取消和显式重试继续使用原有入口。Graph 的“计划操作／前往确认”定位最新现有操作卡，并将焦点交给该卡，支持尚未挂载的长消息流。

节点快照新增可选只读字段 `taskStatus`、`workState`、`progressSummary`、`queueReason`、`reviewOutcome`，来源仍为原生 Task / Attempt / HubWork 与当前候选的有效审核。Work 投影核对计划修订、阶段代次及当前分配尝试；审核结果还核对候选 ID、摘要和审核节点。不因线程存在就称为运行中，不把审核回合 done 当成审核通过，也不把所有任务 done 当成人工出口已放行。旧快照字段缺失时保守显示“已派发／未开始”。

**重试边界：** 当前宿主没有可信的“阻塞条件已解除”事实，Graph 不提供直接重试或自行探测／改变权限。详情引导核对原线程并处理待办；现有操作卡的显式重试能力及服务端校验保留。线程自述只读属于运行报告，不等于已独立验证系统权限，也不证明阻塞已解除。

沿用 Synara Button、胶囊、Popover、Collapsible、字体 token 和共享输入框阴影；弹层与输入框等宽，内部无第二层卡框。折叠动效复用现有 disclosure，运行指示尊重减少动态效果。

窄窗口实测发现原生弹层的碰撞计算仍使用较大的内容测量宽度，会让等宽弹层向左偏移。给现有 Popover 与胶囊透传可选定位容器样式，仅 Graph 指定与锚点等宽，其他调用保持默认。1149px 窗口下弹层与输入框均宽 736px；720px 窗口下两者左边缘均为 20px、宽度均为 677px，轨道内部横向滚动，不挤压输入框。未进行完整移动端触控或全站无障碍审计。

已在无预览参数的隔离实例检查默认收起、展开、真实只读阻塞报告，以及“计划操作”关闭弹层并定位、聚焦既有卡片；没有点击执行、重试或放行。真实模型协作仍停在原有阻塞，未验收审核／放行闭环。

## 上一轮：三段流水线

本轮仅提供前端样式预览，等待用户审核后再接入正式交互。入口为开发页面附加 `?hubGraphPreview=1`；无参数时仍呈现原版 Graph，生产构建不启用该审阅开关。

- 单阶段直接呈现产出、审核、人工放行；不重复阶段标题、依赖段落与角色标签。
- 按定义中的依赖层级分列，同层节点并列，不将并发画成串行。多阶段保留阶段选择；本轮真实页面只验证单阶段场景。

- “回合结束，未提交成果”来自现有 retryable 状态，不推断权限原因。节点没有完整运行状态时不伪造进度。
- “立即重试”只显示演示提示；“查看线程”复用已有跳转。没有新增执行请求、修改权限或推进计划。
- 复用现有 Button、Tooltip、Collapsible、DisclosureChevron、图标与用户字号 token；没有另写折叠动画。
- 输入时自动折叠与真实就地重试暂未接入，等待此次视觉审核。
