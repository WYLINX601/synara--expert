### Context 连接与草稿保护

Context 宿主复用 `WsTransport` 的连接状态和只读 `sessionVersion`，共享查询以原 API、连接代次和项目 / Space 区分；重连开始即暂停，当前代次的实际读取成功后恢复，多观察者共享确认结果。自动保存仍按原 API、数据实例和项目分队列。连接 / 数据所有者变化时，未保存、待回执和结果不确定的草稿保持受保护，显式丢弃才采纳新所有者；首次发送及迁移每次异步返回后再次核对归属。

Space 复用现有字段组件及 `useExpertDraftGuard`，在 Sidebar 挂载离开确认；跨所有者的旧稿保持只读，禁用沿用旧稿覆盖新所有者，明确使用已保存值后切换。保存或放弃后清理 editor 和确认标记，避免影响下一次编辑与跨路由离开。未增加客户端、DTO、路由或通用插件框架。
