# Global MCP V1 交互原型

这是独立可点击原型，不是已实现的 Synara 产品界面。2026-10-04 用户批准按精简方案更新本原型，正式应用实施另行安排。

- 范围：外部工具列表、连接配置、逐专家工具授权、使用情况、停用/退役确认、专家页简化授权入口，以及应用接入的信息组织示例。其它设置不在本原型范围内。
- 数据与执行：离线静态页面，示例数据和改动仅保存在当前页面内存；不连接 API、凭证、数据库或真实任务。检查按钮不会执行真实检查。
- 本地预览地址：`http://127.0.0.1:24745`。
- 审阅顺序：先核对更新后的原型，再确认正式界面实施范围。

## 精简方案

- 分类只在页内标签出现；全局只保留一句演示边界提示。
- 列表使用四个共享字段：连接、全局状态、授权专家、最近检查；不再逐行复述字段或提供同义详情按钮。
- 新建先配置并保存，再进入检查和授权；连接 ID 保存后只读。
- 工具复选框表达选择，标题旁显示已选数量；没有工具时不能保存开启的授权。
- 专家页首次授权先选择工具；已有白名单关闭再开启时保留；全局停用与专家授权分开表达。
- 使用情况合并统计与明细，任务绑定版本保持不变；关闭授权后保留工具的专家仍算引用，删除按钮旁直接说明限制。
- 应用接入统一客户端、配对状态、访问范围和操作字段，不模拟真实凭证或配对成功。

本轮浏览器验收证据和检查结果见 [design-qa.md](./design-qa.md)。
