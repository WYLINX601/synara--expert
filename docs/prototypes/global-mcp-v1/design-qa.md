## 交互核对

以下为本轮实际浏览器操作结果：

- 搜索“浏览器”只显示匹配连接；配置入口可直接打开。
- 保存后的连接 ID 只读；修改服务 URL 后保存，旧检查结果显示过期。已有任务仍显示“固定配置 v7”，不会跟随新配置变化，见[使用情况](./qa/usage-light.jpg)。
- 关闭再开启授权，原选中的两项工具保留；关闭时工具与启动策略不可编辑。
- 清空已开启授权的工具后，保存禁用且理由持续可见，见[空授权状态](./qa/empty-authorization.jpg)。离开时的“保存修改”同样禁用，可放弃或继续编辑。
- 首次授权先选工具：0/3 时不能保存，选择一项并保存后返回原专家页，显示一项授权和开启的开关。
- 关闭代码索引的编程助手授权并保存后，使用情况仍显示“编程助手（已关闭，保留工具） / 1 位”；即使任务与会话均为 0，删除仍禁用，见[保留引用](./qa/retained-reference-dark.jpg)。
- 应用接入按钮打开说明弹窗，明确不会创建凭证、配对客户端或保存范围；Escape 关闭后焦点返回触发按钮。
- 未保存修改弹窗的 Tab 焦点保持在弹窗内，包含反向循环；无效保存按钮不参与焦点循环。
- 当前测试页的警告/错误日志为空。浏览器工具自身出现过审批延迟和联网日志，不属于原型页面错误。
